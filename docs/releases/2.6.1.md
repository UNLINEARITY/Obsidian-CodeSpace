# Code Space Release Notes - 2.6.1

## Overview

Code Space 2.6.1 makes the integrated terminal work on Linux: the terminal support package now installs correctly instead of failing with a checksum or layout error, and the installer handles incomplete local sources gracefully. This release also switches the project license from MIT to AGPL-3.0-or-later.

## Bug fixes

### Terminal support package now installs on Linux

- Installation previously always failed on Linux: the installer required a macOS-only helper file (`spawn-helper`) that the Linux package intentionally does not ship, and the post-extraction step crashed. The install checks now match each platform's real package layout.
- After updating, Linux users can open **Settings → Code Space → terminal** and download the support package normally, then use the integrated terminal as on other platforms.
- The Windows installation check now also verifies the modern ConPTY module, so the settings page reports the installation status more accurately.

### More robust support package sources

- A local `dev-source` folder (used for offline development) that lacks the current platform's entry no longer blocks installation; the installer falls back to the GitHub release automatically. This helps setups where a vault is synced between different operating systems.

## Important notes

### License change: MIT → AGPL-3.0-or-later

- Starting with this release, Code Space is distributed under the [GNU AGPL-3.0-or-later](../LICENSE). Versions up to 2.6.0 remain available under the MIT license they were released with; from 2.6.1 onward, the source code is available on GitHub and distributed modifications must use the same license.
- The zip archives produced for terminal support packages are now fully spec-conformant; packages downloaded with earlier versions keep working and do not need to be re-downloaded.
