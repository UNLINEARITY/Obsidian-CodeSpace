# Code Space Release Notes - 2.6.0

## Overview

Code Space 2.6.0 speaks your files' language. Files saved in GB2312/GBK and other non-UTF-8 encodings now open with correct Chinese text and are saved back in their original encoding instead of being converted, so code that shares its life with compilers and other tools stays byte-stable. This release also adds automatic word wrap for the editor and embeds, Fortran syntax highlighting, and carries the terminal fidelity and font-zoom improvements for every platform.

## Major features

### Non-UTF-8 file encoding support

Legacy-encoded code files finally read and write correctly.

- Open files in GB2312/GBK (GB18030), Big5, Shift JIS, EUC-KR, Windows-1252, and UTF-16 with correct Chinese and CJK text in the editor, embeds, outline, and PDF export.
- Encoding is detected automatically: BOM first, then strict UTF-8 validation, then a configurable fallback (GB18030 for auto detect). A header badge always shows the current encoding — click it (or run "Reopen with encoding") to reopen the file in another encoding.
- Saving writes the file back in its original encoding, so a GB2312 file edited in Code Space remains a GB2312 file on disk. If a file contains characters the encoding cannot represent, Code Space asks how to proceed before writing.
- A new command, "Convert current file to UTF-8", upgrades a file whenever you do want the conversion.
- Each file's encoding choice is remembered, travels with renames, and can be cleared in one click from settings. Works on both desktop and mobile.

### Automatic word wrap

- Long lines now wrap inside the editor and inside embedded code blocks by default — no more horizontal scrolling to read long comments.
- Two independent settings ("Editor word wrap", "Embed word wrap") let you turn wrapping off and return to horizontal scrolling at any time. Printing and PDF export keep their original unwrapped layout.

### Fortran syntax highlighting

- Fixed-form and free-form Fortran (`.f`, `.for`, `.f90`, `.f95`, `.f03`, `.f08`) get syntax highlighting in the editor and in embeds.
- Opt-in by design: add the extensions you need under Settings → Code Space → Managed extensions.

## Improvements

### Terminal fidelity and font zoom

- Terminal colors and the monospace font genuinely follow your Obsidian theme and update immediately on theme changes, including in pop-out windows.
- On macOS, shells start with the correct system locale and a complete login PATH, fixing garbled CJK filenames and missing Homebrew tools; emoji and wide characters align correctly (Unicode 11 width tables).
- Ctrl/Cmd plus wheel zooms the focused terminal only (9-36px), like a native terminal window.

### Official CSS review compliance

- Plugin styles now pass Obsidian's official CSS review: no forced-priority declarations, and only baseline text-decoration forms are used.

## Important notes

- Word wrap is enabled by default. If you prefer the previous horizontal scrolling, disable "Editor word wrap" and "Embed word wrap" in settings.
- The plugin bundle grows to about 2.1 MB to carry the encoding tables required for writing non-UTF-8 encodings on every platform.
- Fortran extensions are not managed by default — add them in settings to take over `.f90` files and friends.
- Existing UTF-8 workflows are unchanged: valid UTF-8 files (with or without BOM) behave exactly as before.
