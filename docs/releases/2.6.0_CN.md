# Code Space 发布说明 - 2.6.0

## 概述

Code Space 2.6.0 开始"说你的文件的语言"。GB2312/GBK 等非 UTF-8 编码的文件现在可以正确打开并按原编码保存回盘，不再被强制转换——与编译器、其他工具共用的代码文件字节稳定。本版本还带来编辑器与嵌入预览的自动换行、Fortran 语法高亮，并包含各平台的终端保真与字号缩放改进。

## 主要功能

### 非 UTF-8 文件编码支持

传统编码的代码文件终于可以正确读写。

- 正确打开 GB2312/GBK（GB18030）、Big5、Shift JIS、EUC-KR、Windows-1252、UTF-16 编码的文件，编辑器、嵌入预览、大纲与 PDF 导出中的中文与 CJK 文本不再乱码。
- 编码自动检测：先识别 BOM，再做严格 UTF-8 校验，失败后使用可配置的回退编码（自动检测默认回退 GB18030）。标题栏徽标始终显示当前编码——点击徽标（或运行"以指定编码重新打开"）即可更换编码重新打开。
- 保存按文件原编码写回：GB2312 文件在 Code Space 里编辑后，磁盘上仍然是 GB2312。若文件包含当前编码无法表示的字符，Code Space 会先询问如何处理再写盘。
- 新增命令"将当前文件转换为 UTF-8"，想升级编码时一键完成。
- 每个文件的编码选择会被记忆，随重命名/移动自动迁移，设置中可一键清除。桌面端与移动端均可用。

### 自动换行

- 编辑器与嵌入式代码块默认对长行自动折行——阅读长注释不再需要左右滚动。
- 两个独立设置（"编辑器自动换行"、"嵌入预览自动换行"）可随时关闭换行、恢复横向滚动。打印与 PDF 导出保持原有不折行版式。

### Fortran 语法高亮

- 固定格式与自由格式 Fortran（`.f`、`.for`、`.f90`、`.f95`、`.f03`、`.f08`）在编辑器与嵌入预览中获得语法高亮。
- 按设计采用自愿开启：在 设置 → Code Space → 管理的文件后缀 中添加所需扩展名即可。

## 改进

### 终端保真与字号缩放

- 终端配色与等宽字体真正跟随 Obsidian 主题，主题切换时立即更新（含弹出窗口）。
- macOS 上 shell 以正确的系统区域设置与完整登录 PATH 启动，修复 CJK 文件名乱码与 Homebrew 工具缺失；emoji 与宽字符正确对齐（Unicode 11 宽度表）。
- Ctrl/Cmd 加滚轮仅缩放当前聚焦终端（9-36px），与原生终端窗口一致。

### 通过官方 CSS 审查

- 插件样式现已通过 Obsidian 官方插件 CSS 审查：不再使用强制优先级声明，text-decoration 仅使用基础形式。

## 重要说明

- 自动换行默认开启。若偏好此前的横向滚动，可在设置中关闭"编辑器自动换行"与"嵌入预览自动换行"。
- 插件包体增长至约 2.1 MB，用于携带在各平台写入非 UTF-8 编码所需的编码表。
- Fortran 扩展名不进默认管理列表——请在设置中自行添加以接管 `.f90` 等文件。
- 既有 UTF-8 工作流完全不变：合法 UTF-8 文件（含或不含 BOM）行为与之前一致。
