# Code Space 发布说明 - 2.6.2

## 概述

Code Space 2.6.2 新增五种界面语言：日语、韩语、德语、西班牙语与巴西葡语均自动跟随 Obsidian 界面语言，每种语言各配一份完整翻译的 README。本版本还带来无需新开标签页即可创建额外终端会话的命令、文件后台加载与重载期间的编辑保护，以及更可靠的外部挂载移除与校验。

## 新功能

### 界面新增五种语言

- 插件界面现支持日语、韩语、德语、西班牙语与巴西葡语，与英文、简体中文并列。语言自动跟随 Obsidian 界面语言，日语（日本）、德语（奥地利）等区域变体会自动匹配到对应基础语言。
- 每种语言覆盖全部 241 条界面文案，并有自动化检查保证翻译随插件演进保持完整。
- 文档为五种语言各提供一份完整翻译的 README，可从每份 README 顶部的语言切换行进入。

### 新命令：新建终端会话

- 新增 **Code Space: 新建终端会话**（New terminal session）命令，在当前聚焦的终端视图或内嵌终端面板中创建额外会话，多开 shell 不再需要每个会话一个 Obsidian 标签页（issue #34）。
- 命令遵守会话数量上限，显示与 **+** 按钮相同的提示，可绑定快捷键；没有打开的终端时回退为打开终端标签页。

## 修复

### 编辑器在文件操作期间保留你的编辑

- 文件仍在解码、或外部变更正在重载时输入的编辑，不再被后台读取的结果覆盖。
- 切换文件或关闭视图后，过期的重载结果会被丢弃，旧版本文件不会再替换你正在编辑的内容。
- 转换文件为 UTF-8 时会等待未完成的解码与保存、固定目标文件，并把期间产生的编辑标记为未保存，而不是丢失。
- 记忆编码适用时，UTF-16 文件保存后保留 BOM；显式以 UTF-8 重新打开文件时按 UTF-8 解码，不再回退自动检测。

### 外部挂载：可靠的移除与更严格的校验

- 链接已不指向配置来源的挂载条目，现在总能从列表移除，并提示如何手动删除残留链接；此前这类条目可能被永久锁死，单个坏挂载还会导致总开关无法关闭。
- 挂载到 `.obsidian`、`.trash` 等隐藏目录现在会被拒绝；Windows 保留设备名、非法字符以及路径段末尾的点与空格同样被拦截。
- macOS 上，源文件夹已被删除的挂载可以正常卸载——包括配置路径仅大小写不同、或位于 `/var` 这类符号链接路径之后的情形。
- Windows 上以 junction 链接类型挂载网络（UNC）文件夹时，现在给出清晰说明而非原始系统错误；挂载创建失败也不再残留空父目录。
- 设置说明与各语言 README 补充警告：云盘同步服务可能跟随挂载链接上传整个挂载文件夹，并建议在同步中排除挂载目录。

## 重要说明

- 自本版本起，GitHub release 页面顶部会自动展示插件预览图，由发布工作流自动添加。
- 自动化测试在 Linux 之外新增 Windows 运行环境，目录联接（junction）等 Windows 专属行为得到持续验证。
