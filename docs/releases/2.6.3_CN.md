# Code Space 发布说明 - 2.6.3

## 概述

Code Space 2.6.3 支持用 Code Space 编辑器编辑笔记中的代码块：把光标放进代码块，选择笔记顶栏的新按钮，代码就会在完整的编辑窗口中打开，保存后写回笔记。本版本还支持把文件拖入终端直接转为路径，并修复了终端偶发的乱码。

## 新功能

### 在 Code Space 中编辑笔记代码块

- 光标位于笔记中的围栏代码块内时，笔记顶栏的阅读/编辑切换按钮左侧会出现一个代码按钮，选择后在 Code Space 编辑窗口中打开该代码块（issue #32）。
- 同一操作也可在命令面板中通过 **Code Space: 在 Code Space 中编辑代码块**（Edit code block in Code Space）执行，可绑定快捷键；编辑器右键菜单中同样提供。
- 窗口按代码块的语言进行语法高亮，支持 `python`、`javascript`、`shell`、`c++` 等常见写法，字号、行号和自动换行跟随你的编辑器设置。
- 选择 **保存** 或按 `Ctrl/Cmd+S` 将代码写回笔记；直接关闭窗口同样会保存，选择 **取消** 则丢弃修改。写回的内容可以像普通编辑一样在笔记中撤销。
- 开头的围栏行（包括语言名和其他参数）原样保留。支持 callout、引用和列表中的代码块，保存时会还原 `>` 标记与缩进。
- 如果窗口打开期间笔记中的代码块发生变化、无法再对应上，Code Space 不会覆盖任何内容，而是把你的修改复制到剪贴板。

### 拖入文件转为终端路径

- 从 Obsidian 文件列表或系统文件管理器把文件、文件夹拖到终端，会粘贴其真实绝对路径；外部挂载中的文件解析到磁盘上的实际位置。
- 路径按当前 shell（zsh、bash、PowerShell 或 cmd）自动加引号，含空格、引号或中文的名称可以直接使用；支持一次拖入多个文件。
- 路径以粘贴方式写入，不会被执行，可以继续输入命令的其余部分。

## 修复

### 终端显示

- 修复终端偶发乱码或显示错字的问题。GPU 渲染器现与内置终端版本匹配，图形上下文丢失时（例如 macOS 休眠唤醒或切换显卡后）能正确回退到标准渲染器。
- 终端重新显示或窗口重新获得焦点时会重建字形缓存，缓存损坏导致的错字会自动纠正。

## 重要说明

- 代码块编辑在编辑模式（含实时预览）下可用；阅读模式没有光标，因此不显示按钮和命令。
- 七种语言的 README 已补充代码块编辑与拖入文件到终端的说明。
