# Code Space 发布说明 - 2.6.1

## 概述

Code Space 2.6.1 让集成终端在 Linux 上真正可用：终端支持包现在可以正确安装，不再以校验或布局错误失败，安装器对不完整的本地同步源也能妥善处理。本版本同时将项目许可证由 MIT 切换为 AGPL-3.0-or-later。

## 修复

### 终端支持包在 Linux 上可正常安装

- 此前 Linux 上安装必然失败：安装器强制要求一个仅 macOS 资产携带的辅助文件（`spawn-helper`），且解压后的处理步骤会崩溃。现在安装校验与各平台的真实资产布局一致。
- 更新后，Linux 用户在 **Settings → Code Space → terminal** 中即可正常下载支持包，随后与其他平台一样使用集成终端。
- Windows 的安装检测同时校验现代 ConPTY 模块，设置页的安装状态显示更准确。

### 更健壮的支持包来源

- 本地 `dev-source` 文件夹（离线开发用）缺少当前平台条目时不再阻断安装，安装器会自动回退 GitHub release。这对在多个操作系统间同步 vault 的环境尤其友好。

## 重要说明

### 许可证变更：MIT → AGPL-3.0-or-later

- 自本版本起，Code Space 以 [AGPL-3.0-or-later](../LICENSE) 分发。2.6.0 及之前的版本仍按其发布时的 MIT 许可证提供；自 2.6.1 起源码继续在 GitHub 开放，分发的修改版需采用相同许可证。
- 终端支持包的 zip 归档现在完全符合规范；此前版本下载的包可继续使用，无需重新下载。
