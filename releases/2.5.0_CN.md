# Code Space 发布说明 - 2.5.0

## 概述

Code Space 2.5.0 为桌面端带来集成终端：在编辑器内嵌面板与全屏终端标签页中运行真实 PTY shell，采用按需启用设计，所有网络下载均为显式操作。终端按页面分组管理，每组拥有独立标签栏；编辑器内嵌面板可将正在运行的终端原样移交到新的终端标签页。渲染跟随 Obsidian 主题并使用 WebGL 渲染器，同时新增 CI 工作流为全部受支持平台发布经校验的预编译二进制。

## 新功能

### 集成终端（仅桌面端）

运行真实系统 shell——Windows 上为 PowerShell，macOS/Linux 上为 zsh 或 bash——由 xterm.js 与 node-pty 驱动。

- **真实 PTY 体验**：颜色、交互式程序、任务控制与分页均与原生终端一致（Windows 使用 ConPTY，其余平台使用 Unix pty），进程退出时显示暗色提示行
- **终端标签页与独立分组**：每个终端标签页拥有独立的一组终端和完整标签栏——点击切换、逐标签关闭、加号新建；关闭标签页即关闭该组终端，重新打开为全新一组
- **编辑器内嵌面板**：编辑器底部的可拖拽调高快速终端面板（拥有独立分组），并支持将正在查看的终端**移交**到新终端标签页——进程、回溯与输出原样保留
- **主题联动渲染**：配色与等宽字体跟随 Obsidian 主题（含弹出窗口）；WebGL 渲染器保证文字锐利、滚动流畅，不可用时自动回退 DOM 渲染
- **跟随上下文的工作目录**：新终端默认在当前活动文件所在文件夹启动，外部挂载会解析到真实磁盘路径

### 按需启用与显式下载

终端默认关闭，所有网络操作均由用户主动发起。

- 打开终端开关后首先显示支持文件区块；shell、字体大小、回溯与上限设置在支持文件就绪后才出现
- 终端命令与编辑器头部按钮仅在启用且就绪后可见，自身绝不触发下载
- 预编译的 `node-pty` 支持包（每平台约 1-3 MB，SHA-256 校验）仅通过设置中的**下载**按钮显式获取——因为插件商店只分发 JavaScript
- 支持文件可随时安全移除：未锁定文件立即删除，被当前会话占用的文件将在 Obsidian 重启后自动完成移除

## 平台与开发者说明

- 支持平台：Windows x64/ARM64、macOS x64/ARM64、Linux x64（Linux 安装需要 `unzip`）
- 新增 CI 工作流为独立的 release tag 构建各平台二进制，与插件版本解耦；重跑工作流可安全覆盖资产
- 本地终端开发完全离线：`npm run pty:assets` 构建当前平台支持包，安装器优先使用本地 dev-source，回退到 GitHub release
- 会话上限按全部终端组总数裁决，优先淘汰当前组内已退出的会话
