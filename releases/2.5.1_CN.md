# Code Space 发布说明 - 2.5.1

## 概述

Code Space 2.5.1 让集成终端的外观与行为向原生终端看齐：配色与等宽字体真正跟随 Obsidian 主题，macOS 的 shell 以正确的区域设置与完整的 PATH 启动，emoji 等宽字符对齐无误，并支持 Ctrl/Cmd 加滚轮单独调整每个终端的字号。

## 改进

### 正确的主题与字体渲染

终端现在真正与你的 Obsidian 主题匹配。

- 配色与等宽字体跟随当前主题，切换主题时立即更新（含弹出窗口）。
- 编辑器内嵌面板与终端标签页中的文字选中样式完全一致。

### 可靠的 macOS 与 Linux shell

各平台的 shell 均以正确的环境启动。

- macOS 上，终端以系统区域设置启动，修复非 ASCII 文件名与命令输出乱码；并以完整登录 PATH 加载，Homebrew 等安装的工具可正确解析。
- emoji 与其他宽字符正确对齐（Unicode 11 宽度表）。
- Linux 上以标准交互模式启动 shell，不执行登录 profile，首屏干净。

### 终端字号缩放

- Ctrl/Cmd 加滚轮仅调整当前聚焦终端的字号（9-36px），与原生终端窗口一致；默认字号仍可在设置中配置，并对每个新终端生效。
