# Code Space Release Notes - 2.5.1

## Overview

Code Space 2.5.1 makes the integrated terminal look and behave like a native terminal. Theme colors and the monospace font now truly follow your Obsidian theme, macOS shells start with the correct locale and a complete PATH, emoji align at the right width, and each terminal can zoom its own font size with Ctrl/Cmd plus wheel.

## Improvements

### Correct theme and font rendering

The terminal now genuinely matches your Obsidian theme.

- Colors and the monospace font follow the active theme and update immediately when the theme changes, including in pop-out windows.
- Text selection looks identical in the embedded editor panel and in terminal tabs.

### Reliable macOS and Linux shells

Shells start with a correct environment on every platform.

- On macOS, the terminal starts with your system locale, fixing garbled non-ASCII filenames and command output, and loads the full login PATH so tools installed via Homebrew and similar resolve correctly.
- Emoji and other wide characters align correctly (Unicode 11 width tables).
- On Linux, shells start in the standard interactive mode without executing login profiles, keeping the first screen clean.

### Terminal font zoom

- Ctrl/Cmd plus wheel adjusts the font size of the focused terminal only (9-36px), exactly like a native terminal window. The default size remains configurable in settings and still applies to every new terminal.
